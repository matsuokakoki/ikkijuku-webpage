# 先生の編集ガイド

管理画面: https://sm01hn94ba.microcms.io/

## お知らせ

「お知らせ」で記事を追加・編集します。「タイトル」と「内容」を入力してください。公開日時が一覧の日付になります。過去の記事は公開日時を変更できます。下書きで保存した内容は公開サイトに出ません。

## 募集状況・授業時間・料金・実績概要

同名のメニューで編集します。募集状況、平日・土曜・日曜の時間、中学生・高校生の料金、補足、受講例を変更できます。合格実績の見出しと学校一覧もこの画面です。日付や税込表記など、表示したい内容をそのまま入力してください。

## 年度別実績

「年度別の合格実績」で年度ごとのレコードを作成します。年度は重複させないでください。高校生・浪人生・中学生の人数と、大学・高校・中学の学校一覧を入力します。学校ごとに学部・学科、合格人数、備考を設定できます。人数を省略した場合は公開サイトにも人数を出しません。

## 休講日

「休講日カレンダー」で月ごとのレコードを作成します。対象月は`2026-10`の形式で入力し、「休講日」に日付を追加してください。月が重複した場合や、異なる月の日付を入れた場合は公開ビルドが止まります。

未来の月を準備するときは下書きにしておき、案内を始めるときに公開します。公開終了した月はサイトから除かれます。日曜日は定休日として案内しています。

## 公開の確認

CMSの「公開」はデータを公開する操作です。サイトへの反映にはビルドが必要で、即時反映ではありません。Webhookと自動デプロイが接続されたら、公開後に数分待ってサイトを確認してください。接続前は開発者による再配信が必要です。

紹介文・写真・レイアウトはコードで管理します。先生が編集する必要はありません。
